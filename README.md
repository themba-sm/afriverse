# AFRIVERSE website

Premium marketing site for AFRIVERSE, an AI automation and integration company.

- React 18 + Vite 6, no UI dependencies
- `src/data/site.js`: all content (services, industries, workflows, plans, FAQs)
- `src/styles.css`: design system tokens, type, buttons, cards
- `src/sections.css`: section and component styles (mobile-first)
- `public/brand/`: official logo assets (cropped/resized from the supplied logo, never redrawn)

```
npm install
npm run dev
npm run build
```
